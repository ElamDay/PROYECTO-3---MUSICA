# Proyecto 3 - Análisis de preferencias musicales

Proyecto desarrollado durante el Bootcamp de Data Science de TripleTen.

## Descripción

Este proyecto analiza datos de reproducción de música con el objetivo de estudiar el comportamiento y las preferencias musicales de los usuarios.

El análisis compara la actividad de los usuarios de distintas ciudades y estudia cómo varían sus hábitos de escucha según el día de la semana y el género musical.

## Objetivos

- Explorar y preparar los datos para el análisis.
- Identificar y tratar valores ausentes y duplicados.
- Estandarizar los datos cuando sea necesario.
- Analizar la actividad musical de los usuarios.
- Comparar el comportamiento de los usuarios de diferentes ciudades.
- Analizar las preferencias de géneros musicales.
- Comprobar hipótesis relacionadas con los hábitos de escucha.
- Obtener conclusiones a partir de los resultados.

## Tecnologías utilizadas

- Python
- Pandas
- Jupyter Notebook

## Archivos

- `BP_project_template_ES_updated.ipynb`: notebook principal con el análisis completo.
- `music_project_en.csv`: conjunto de datos utilizado en el análisis.
- `requirements.txt`: librerías necesarias para ejecutar el proyecto.
